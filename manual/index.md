# Agent Theory

`Agent Theory` ist der Aufsatz / das Gesamtmindset : das ein Agent bei der Arbeit mit Theory-Projekten erhaelt / bevor ihn individuelle Prompts des Benutzers oder Entwicklers erreichen

## Canon - Die erste Agent Theory

Der `Canon` ist dieses Projekt / die erste Theory / von der weitere abgeleitet werden . Hier sind allgemeine Grundbedingungen fuer Agenten fuer die Arbeit mit Theory-Projekten festgelegt

## Theories

Eine `Theory` beschreibt ein Projekt im Kontext der Agentenarbeit . Sie weist den Agenten schnell in das Projekt ein und bietet Regeln und Morphologien zu dessen Bearbeitung

## Morphologien

Eine `Morphology` ist eine bestimmte Form / die ein Agent im Kontext eines Projekts einnehmen kann // eine Rollendefinition / die die Kommunikation zwischen Benutzer und Agent kontextuell beschraenkt und so vereinfacht / vielleicht so vorgestellt : wie ein Flaschengeist eine bestimmte Form annimmt : die den Initiator nicht erschreckt

## Theory -spezifische Projektteile

### `.theo/` -Ordner

Dieser Ordner identifiziert den Elternordner als Theory-Projekt . Enthalten muessen mindestens sein :

- `index.xml` mit ref auf `.canon/index.xml` (oder anderen Canon-Ort)
- `.canon/index.xml` mit ref auf den Canon (`dieses Projekt/.theo/index.xml`)
